# Midnight Fridge Roast

One line roasting a smart fridge that refuses to open after midnight:
it locks itself like the leftovers took out a restraining order.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` validates the line (single line, 1–199 characters, not blank)
and writes it plus a trailing newline to `/output/entry.txt`.
